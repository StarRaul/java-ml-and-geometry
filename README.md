# Applied AI, Machine Learning & Computational Mathematics in Java

A collection of algorithms and systems implemented in Java, exploring computer vision, supervised classification models, and analytical geometry.
## Projects Overview

### 1. Facial Recognition System (`AI_FacialRecog`)
An algorithmic solution developed to process visual features, detect facial structures, and perform identity matching based on input training datasets.

### 2. Support Vector Machine (`SVM`)
Implementation of a Support Vector Machine classifier designed to map feature vectors, compute decision boundaries (hyperplanes), and categorize multidimensional data points.

### 3. Conic Sections Analyzer (`Conice`)
A mathematical program that analyzes second-degree algebraic equations to determine invariants, classify conic sections (ellipses, parabolas, hyperbolas), and compute geometric properties.
